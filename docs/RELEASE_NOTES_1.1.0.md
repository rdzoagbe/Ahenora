• A simpler layout: Feed, Calendar, Kids and Kitchen, always one tap away

### Notes
- **Rebrand-first framing:** "same app… new name" is the lead so existing users aren't confused by the name change on their home screen. The nav + "+" are the concrete improvements.
- Keep the bullet symbol `•` — it renders fine in Play "What's new".
- If you'd rather not use the 💛 emoji, drop it; both stay well under 500 without it.
- **Shorter alternative** if you want it tighter (EN, 188 chars):
  ```
  We're now Ahenora — same app, new name, new look. Simpler navigation, and a new "+" to add a task, note, photo or voice memo in one tap. Thanks for being here. 💛
  ```
